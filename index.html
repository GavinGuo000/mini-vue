mini-vue

从零实现 Vue3 核心原理 · 响应式 + 虚拟 DOM + 编译器

必须通过本地服务器打开（ES Module 限制）。在项目根目录运行 npm run dev，然后访问 http://localhost:5173。

① 响应式系统

reactive / ref / computed / watch / effect 的依赖收集与派发更新

② 虚拟 DOM 渲染

用 h() 手写 render，观察 diff 如何最小化 DOM 操作

③ 模板编译器

template 字符串 → AST → render 函数的全过程

④ 综合：TodoMVC

把三大模块组合成一个完整的小应用
